# 08 · 命名主题

> 状态：已实现，待签收
> 前置：0.4.1 已发布

## 1. 目标

在**不改动现有亮色与暗色**的前提下，加入一组主流配色主题，让用户能在设置里直接比较并切换。主题同时覆盖界面（侧栏、标签栏、工具栏、状态栏、弹窗）与编辑器 token，原生标题栏、菜单和对话框跟随主题的亮 / 暗基准。

## 2. 范围

### 做

- 主题注册表：默认亮 / 暗，加 10 套命名主题。
- 设置 → 外观里的下拉选择，选项名称后标注浅色 / 深色，切换立即应用并持久化。
- 原生菜单保留「亮色 / 暗色 / 跟随系统」，另加「更多主题…」打开设置；工具栏不设主题按钮。
- 命名主题固定亮 / 暗，`mygo.Theme.SetSource` 跟随其基准；「跟随系统」只切默认亮 / 暗。
- 旧配置兼容：`light` / `dark` / `system` 行为不变，未知 id 回退 `system`。
- 对比度与 token 完整性测试。

### 不做

- 自定义主题 JSON 导入 / 导出。
- 「跟随系统」时按主题做明暗配对（如 One Light / One Dark 自动切换）。
- 官网截图全量重拍。

## 3. 主题清单

| 主题 | 基准 | 风格 |
| --- | --- | --- |
| One Dark | 暗 | Atom 经典，灰蓝底、紫绿高亮 |
| Dracula | 暗 | 紫粉高饱和 |
| Nord | 暗 | 极地蓝灰，低饱和 |
| Tokyo Night | 暗 | 深海军蓝 + 霓虹蓝紫 |
| Catppuccin Mocha | 暗 | 柔和粉彩 |
| GitHub Light | 亮 | 中性干净 |
| One Light | 亮 | One Dark 的浅色版 |
| Solarized Light | 亮 | 暖米色底 |
| Catppuccin Latte | 亮 | 柔和粉彩浅色 |
| Gruvbox Light | 亮 | 复古暖黄 |

默认的「亮色」「暗色」保持 0.4.1 的色值。后续候选：Solarized Dark、Gruvbox Dark、Monokai、Rosé Pine、Everforest、Kanagawa。

色板取自各项目的公开配色，均以 MIT 或同类开放许可发布；本项目只使用颜色值，不包含对方代码，主题名仅用于标识风格。

## 4. 实现

- `internal/theme/theme.go`：`Definition`（UI 调色板、`Chrome`、编辑器调色板）、注册表、`Resolve` / `Normalize`、默认两套的原样构建、对比度工具。
- `internal/theme/builtin.go`：每套命名主题只写约 18 个种子色，悬停、按下、选区、焦点环、滚动条、查找高亮与其余 token 由规则派生。
- `internal/app/app.go`：`Settings.Theme` 是唯一真源；`Dark` 只表示当前基准；`setThemeID` 保存、切换原生外观并重绘。
- `internal/app/settings_ui.go`：外观区改为下拉选择，选项为「跟随系统 / 亮色 / 暗色」加 10 套命名主题；命名主题的名称靠左、浅色 / 深色标注固定靠右。
- `internal/app/settings_ui.go`：设置弹窗改为卡片分组（700×640），每组标题带图标，卡片内每行左侧标题 + 说明、右侧控件，行间用细分隔线；窄窗口下控件移到标题下方。设置里的所有下拉改用 `SelectBase` 自绘，触发器与弹层沿用主题样式，选项悬停显示小手。
- `internal/app/menu.go`：原生菜单的主题子菜单从设置值判断勾选，末尾「更多主题…」打开设置；`view.go` 移除工具栏上的主题按钮。
- `internal/settings/settings.go`：不再把未知主题重置为 `system`，由 app 对照注册表校验。
- 新增文案：`themeLightTag`、`themeDarkTag`、`moreThemesEllipsis`（中英）。

## 5. 验证

- `go test ./...`、`go vet ./...`、`go build ./...` 通过。
- 主题测试：10 套命名主题齐全、ID 唯一、每套 25 类 token 全部着色、正文 / 弱文字 / 强调文字与背景达到 WCAG 对比度；默认亮 / 暗的关键色值与旧版一致。
- 应用测试：切换命名主题立即生效并写盘、重启恢复；未知主题回退 `system`；设置下拉展开后，鼠标移到选项上时 `Tester.Cursor()` 为 `CursorPointer`。
- 用 `ui.Tester` 为默认两套与 10 套命名主题各渲染一张编辑器和设置面板截图，人工检查侧栏、标签、查找高亮、Markdown 代码块、卡片分隔线与浅色阴影；另在窄窗口下检查控件换行。

## 6. 已知限制

- 主题名保持英文，不随界面语言翻译；浅色 / 深色标注与「更多主题…」已本地化。
- 命名主题是固定明暗；想要跟随系统只能使用默认亮 / 暗。
- 主题选择只做内置色板，不支持导入用户主题文件。
