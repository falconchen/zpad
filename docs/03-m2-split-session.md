# 03 · M2 左右双栏与会话恢复

> 预估：1–2 天
> 前置：M1 已签收

## 1. 目标

把单栏编辑器扩展为**左右双栏 + 每栏独立标签**，并让窗口在下次启动时
恢复工作区、标签、分屏和滚动位置；同时补齐关闭 / 退出时的未保存汇总提示。

## 2. 范围

### 做

- 左右两栏，中间可拖拽分隔线。
- 每栏独立的标签列表、当前标签、光标与滚动。
- 分屏开关、关闭右栏并合并标签。
- 活动栏跟随焦点；工具栏、菜单、状态栏作用于活动栏。
- 会话保存与恢复。
- 关闭标签 / 关闭窗口 / 退出应用的未保存提示。
- 窗口标题、macOS 关闭按钮的未保存状态。
- 测试。

### 不做

- 上下分屏、三栏以上。
- 标签拖拽排序（二期）。
- 热退出恢复未保存内容（二期）。
- 外部修改监听（二期）。

## 3. 数据模型

```go
type Tab struct {
    doc   *Document
    state *editor.State
}

type Pane struct {
    tabs   []*Tab
    active int
}

type Workspace struct {
    root       string
    docs       map[string]*Document // 按绝对路径去重
    left       Pane
    right      Pane
    split      bool
    splitWidth float32
    activePane int // 0=左 1=右
}
```

- 同一个文件可以在左右两栏各有一个标签：共享 `Document.Buffer`，但各自有 `editor.State`，光标与滚动互不影响。
- `docs` 以绝对路径为键；最后一个标签关闭时视情况从 `docs` 移除。
- 右栏关闭时，把右栏标签并入左栏，按路径去重。

## 4. 任务拆解

### 4.1 分屏布局

- [ ] 根内容区：

```go
if app.split {
    ui.Split(c, &app.splitWidth, app.leftPane, app.rightPane).Fill()
} else {
    app.leftPane()
}
```

- [ ] 使用 `ui.Split`，分隔线默认宽度 50%，最小保留 40 DIP。
- [ ] `splitWidth` 持久化；窗口过窄时由 `ui.Split` 自身收缩。
- [ ] 工具栏提供“切换分屏”按钮；`Cmd+\` 快捷键。
- [ ] 分屏开启时，右栏默认打开当前文件的一个新标签（复制当前文档引用，新建 `editor.State`）。
- [ ] 关闭右栏：
  - 把右栏标签并入左栏。
  - 相同路径只保留左栏的一份。
  - 活动栏切回左栏。
  - 右栏的空状态不保留。

### 4.2 每栏独立标签

- [ ] 左栏、右栏各自渲染自己的标签栏。
- [ ] 每个标签独立保存：光标、选区、滚动、折叠状态。
- [ ] 切换栏或标签时，焦点请求到对应的编辑器。
- [ ] 活动栏判断：
  - 任一标签的 `state.Focused()` 为真 → 该栏为活动栏。
  - 点击标签栏、状态栏操作的栏也要能主动设为活动栏。
- [ ] 标签关闭后，若该栏为空，显示该栏的空状态，不自动关闭整栏。
- [ ] 同一文件在两栏同时打开时，编辑任一侧，另一侧同步显示（共享 Buffer）。

### 4.3 状态栏与命令作用域

- [ ] 状态栏显示活动栏当前标签的信息。
- [ ] 保存、另存为、关闭标签、查找、大小写等命令作用于活动栏。
- [ ] 侧栏打开文件时，默认进入活动栏。
- [ ] 工具栏的“保存”“撤销”等按钮根据活动栏状态启用 / 禁用。

### 4.4 会话保存

- [ ] 扩展 `session.State`：

```go
type TabState struct {
    Path    string  `json:"path"`
    ScrollY float32 `json:"scrollY"`
}

type PaneState struct {
    Tabs   []TabState `json:"tabs"`
    Active int        `json:"active"`
}

type State struct {
    Root         string    `json:"root"`
    Split        bool      `json:"split"`
    SplitWidth   float32   `json:"splitWidth"`
    ActivePane   int       `json:"activePane"`
    Left         PaneState `json:"left"`
    Right        PaneState `json:"right"`
    SidebarOpen  bool      `json:"sidebarOpen"`
    SidebarWidth float32   `json:"sidebarWidth"`
}
```

- [ ] 保存时机：
  - 窗口关闭前。
  - 应用退出前。
  - 布局变化后防抖 1 秒（可选）。
- [ ] 恢复时机：
  - 窗口创建后、第一帧之前读取。
  - 依次打开文件；缺失文件跳过并 toast 提示。
  - 恢复活动标签与滚动位置。
- [ ] `settings.RestoreSession` 为 false 时，只恢复窗口大小，不恢复标签。
- [ ] 会话写入使用原子写，损坏时回退为空会话。

### 4.5 关闭与退出

- [ ] 统一的关闭协调器，避免窗口关闭与退出重复弹窗：

```go
type closeRequest struct {
    reason string // "tab" | "window" | "quit"
    done   chan bool
}
```

- [ ] 关闭单个标签：只检查该标签。
- [ ] 关闭窗口 / 退出：收集所有栏中所有未保存文档（按路径去重）。
- [ ] 汇总对话框：

```text
有 3 个文件未保存，是否保存？
[保存全部] [不保存] [取消]
```

- [ ] 保存全部：
  - 逐个保存；未命名文件走另存为。
  - 任一取消或失败 → 中止关闭，保留窗口。
- [ ] 不保存：直接关闭 / 退出。
- [ ] 取消：中止关闭。
- [ ] 关闭协调器需要重入保护：对话框打开期间再次触发关闭应被忽略。
- [ ] macOS `Cmd+Q` 通过 `App.OnBeforeQuit` 进入同一流程。
- [ ] 关闭完成后清理会话、保存窗口状态。

### 4.6 窗口状态

- [ ] 活动标签未保存时：
  - `win.SetDocumentEdited(true)`
  - macOS 关闭按钮显示圆点。
- [ ] 活动文件有路径时：
  - `win.SetRepresentedFile(path)`
- [ ] 标题：
  - 有文件：`文件名 — ZPad`
  - 无文件：`ZPad`
  - 有工作区但无文件：`工作区名 — ZPad`
- [ ] 标题不显示 `*`，未保存状态交给系统圆点 / 标签圆点。

### 4.7 测试

- [ ] 会话 JSON 往返测试。
- [ ] 分屏视图测试：开启分屏、两栏各开一个文件、状态栏跟随活动栏。
- [ ] 关闭右栏合并标签测试：重复路径去重。
- [ ] 关闭协调器测试：用假的确认器与保存器，覆盖保存全部 / 不保存 / 取消三条路径。
- [ ] 会话恢复测试：写入临时会话 → 重建 → 断言标签、活动栏、滚动。
- [ ] `go test ./...` 通过。

## 7. 风险与备注

- `ui.Split` 只支持两个窗格，正好满足一期“只做左右两栏”。
- 关闭协调器必须防止 `OnClose` 与 `OnBeforeQuit` 互相触发导致的重复对话框。
- 恢复滚动位置需要在编辑器完成首次布局后设置，必要时延迟一帧。
- 同一文件双栏共享 Buffer 是 MyGo 编辑器原生支持的能力；仍需验证撤销历史与选区同步行为。

完成日期：2026-11-22。

已实现：

- 左右 pane 模型：每栏独立标签、当前标签、编辑器状态与滚动位置。
- 同一文件在左右栏时共享 `Document` 和 `Buffer`，各自保留光标与选区。
- 分屏开关、分隔线拖拽、关闭分屏时把右栏标签并入左栏并按文档去重。
- 活动栏跟随标签点击 / 编辑器焦点；状态栏显示「左栏 / 右栏」。
- 工具栏分屏按钮、显示菜单「切换分屏」与 `Cmd+\`。
- 会话保存 / 恢复：工作区、分屏、分隔线宽度、活动栏、左右标签、活动标签、滚动位置、侧栏开关与宽度。
- 关闭窗口 / 退出应用未保存汇总：保存全部 / 不保存 / 取消；未命名文件逐个另存为。
- 重复弹窗防护：`closePromptOpen` 与 `allowClose` / `allowQuit` 协调 `OnClose` 与 `OnBeforeQuit`。
- 系统结束会话时尽力同步保存已有路径的文件，不再弹窗。
- 窗口标题：活动文件优先，否则显示工作区名，再否则 `ZPad`。
- 活动标签未保存时更新 macOS 关闭按钮状态。
